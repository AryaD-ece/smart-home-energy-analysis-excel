## 🧠 Problem Statement

> Smart home systems generate continuous energy data, but without structured analysis, this data remains underutilized.

This project builds a **complete Excel-based analytical pipeline** to convert raw data into meaningful insights.

---

## 🏗️ Data Pipeline

```text
Raw Data → Cleaning → Feature Engineering → Classification → Visualization
```

---

## ⚙️ Methodology

🔹 **Data Processing**

* Cleaned and structured raw dataset
* Standardized time-series format

🔹 **Feature Engineering**

* Extracted hour from timestamps
* Created time segments (Morning, Afternoon, Evening, Night)

🔹 **Classification Logic**

* Defined threshold using average consumption
* Categorized usage into High vs Normal

🔹 **Data Mapping**

* Implemented:

  * VLOOKUP
  * HLOOKUP
* Simulated relational mapping
