# Smart Home Energy Consumption Analysis (Excel)

> End-to-end data analysis project using Excel on real-world smart home energy data.

---

## 📌 Overview
This project analyzes smart home energy consumption data using Microsoft Excel as part of the course **Data Analysis using Excel**.

The objective was to extract meaningful insights from time-series data using fundamental data analysis techniques.

---

## 📂 Dataset
- Source: Kaggle  
- Link: https://www.kaggle.com/datasets/taranvee/smart-home-dataset-with-weather-information  

---

## 🛠️ Features Implemented
- Data cleaning and preprocessing  
- Feature engineering (hour extraction, time segmentation)  
- Threshold-based classification (High vs Normal usage)  
- Lookup operations using VLOOKUP and HLOOKUP  
- Data visualization using Excel charts  

---

## 📊 Key Insights
- Energy consumption varies significantly over time  
- Weak correlation between temperature and energy usage  
- Majority of usage falls under normal usage  
- Device-level analysis highlights energy usage patterns
